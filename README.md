# Todo App

A small todo list built with React and [Vite](https://vite.dev/).

## Available Scripts

### `npm start` / `npm run dev`

Runs the dev server at [http://localhost:3000](http://localhost:3000) with hot module replacement.

### `npm run build`

Builds the app for production into the `dist` folder.

### `npm run preview`

Serves the production build locally to check it before deploying.
